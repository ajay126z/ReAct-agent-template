# Design notes

## Why Copier

The template is meant to be updated, not just copied. Copier stores answers in
`.copier-answers.yml` and can replay them with `copier update`, which keeps the
scaffold from rotting in every generated project.

## What is copied from the reference project

`ReActAgentWithMCP` is the working reference. The template keeps the parts that
were hardest to get right:

- the forgiving ReAct parser and its tests
- the `stop=["Observation:"]` contract and forced-final pass
- the `ToolSpec` / `ToolResult` boundary
- the JSONL tracer and bounded session memory
- the careful stdio environment handling

It drops project-specific surfaces: the notes corpus, web tools, elicitation,
OpenTelemetry export, the raw JSON-RPC demo client, resources, prompts, and
completions. Those are good features but not part of a minimal agent core.

## Deliberate simplifications

- **One `llm.py` file.** All adapters share one protocol and one error type.
  Splitting them per file adds import wiring without much clarity at this size.
- **One `client.py`.** The base types stay separate because tests and the agent
  import them without the MCP SDK.
- **Two sample tools.** Calculator demonstrates deterministic, sandboxable
  logic; current time demonstrates a default argument. Both are trivial to
  test.
- **No native tool calling.** Text ReAct keeps reasoning visible and makes the
  loop easy to teach and debug. A native-tool-calling variant is a reasonable
  follow-up, not a v1 requirement.
- **Tracing is always in the tree.** `enable_tracing` controls whether traces
  are written by default. Keeping the module avoids conditional imports in the
  loop and adapters.

## Rendering rules

- Optional files are removed with templated `_exclude` entries.
- Feature flags appear as Jinja blocks at the smallest possible scope.
- Python code avoids `{{` outside intended substitutions; JSON examples use
  single braces.
- Every rendered combination must lint and pass tests. The fast matrix renders
  every answer combination; the slow suite installs and tests the default
  project end to end.

## Compatibility

- Python 3.12+.
- `mcp[cli]>=2.3,<3`; the SDK's transport APIs are the main drift risk.
- `uv_build` for packaging, `uv` for environments.
- No CI is generated by default; add the workflow that matches your host.
